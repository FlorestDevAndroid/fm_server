# FLORESTMESSANGER SERVER

📡 FM Server — Локальный WebSocket Чат-Сервер для Android
FM Server — это автономное Android-приложение, превращающее ваш смартфон в полноценный локальный сервер WebSocket-чата. Приложение создано для мгновенного обмена сообщениями в условиях полного отсутствия интернета и сотовой связи (в походах, на природе, в подвальных помещениях или закрытых локальных сетях).

🚀 Ключевые особенности
📶 Работа без интернета: Нужна только локальная Wi-Fi сеть или точка доступа (Hotspot), разданная прямо с телефона-сервера.

🔋 Неубиваемый фоновый режим: Сервер работает как Foreground Service с захватом WifiLock, гарантируя стабильную работу при заблокированном экране и предотвращая переход Wi-Fi в спящий режим.

⚡ Низкие задержки: Построен на базе библиотеки NanoWSD (NanoHTTPD) для быстрой дуплексной связи через WebSockets.

💓 Heartbeat (Ping/Pong): Фоновый процесс каждые 10 секунд проверяет активность подключенных клиентов, исключая обрывы соединений.

💬 История сообщений: Хранит в памяти последние 200 сообщений и автоматически передаёт их новому пользователю при подключении.

🌐 Встроенная веб-страница: При переходе на IP-адрес сервера через обычный браузер отображается веб-страница со статусом работы и количеством онлайн-клиентов.

🛠 Архитектура и стек технологий
Язык: Java

Network & WebSockets: NanoHTTPD / NanoWSD (легковесный HTTP/WebSocket сервер)

Формат данных: org.json.JSONObject (для валидации и разбора JSON-пакетов)

Android Components: Foreground Service, NotificationChannel, WifiManager.WifiLock

📂 Структура проекта
FMServer.java — Базовый сервер на NanoWSD, обработчик REST-эндпоинтов (/, /status, /history) и WebSocket-хэндшейка.

ChatService.java — Foreground Service, удерживающий процесс сервера в памяти и контролирующий WifiLock.

ClientManager.java — Менеджер подключений: отвечает за рассылку (broadcast), хранение истории и регулярные Ping кадровые проверки.

ChatWebSocket.java — Обработчик клиентских сокетов, текстовых сообщений, статусов входа (join) и набора текста (typing).

Message.java — Модель сообщений и сериализация в JSON.

MainActivity.java — Интерфейс управления запуском/остановкой сервера и отображения IP-адреса.

🔌 Подключение клиентов
Клиенты могут подключиться, используя FM-Client.


🏕 Инструкция по использованию в походе
Включите Точку доступа (Wi-Fi Hotspot) на смартфоне, где установлен FM Server (мобильный интернет включать не требуется).

Запустите приложение FM Server и нажмите «Запустить сервер».

На экране отобразится IP-адрес (например, 192.168.43.1).

Другие участники подключаются к вашей Wi-Fi сети.

Открывают клиентское приложение-чат и вводят IP-адрес сервера и порт 3550.

📦 Сборка и установка
Клонируйте репозиторий.

Откройте проект в Android Studio.

Соберите проект: Build -> Build Bundle(s) / APK(s) -> Build APK(s).
