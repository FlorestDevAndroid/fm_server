# 📡 FlorestMessenger — FM Server

**FM Server** — автономное Android-приложение, превращающее смартфон в полноценный локальный **WebSocket-чат-сервер**.

Сервер работает полностью **без интернета и сотовой связи** — достаточно локальной Wi-Fi сети или точки доступа (Hotspot), созданной непосредственно на смартфоне-сервере.

> 🏕 Идеально подходит для походов, выездов на природу, подвальных помещений, закрытых объектов и любых ситуаций, где отсутствует интернет.

---

## 🚀 Возможности

### 📶 Работа без интернета

FM Server не требует подключения к интернету.

Для работы достаточно:

* 📱 смартфона с FM Server;
* 📡 локальной Wi-Fi сети или Hotspot;
* 💬 устройств клиентов.

Мобильный интернет **не требуется**.

---

### 🔋 Надёжная работа в фоне

Сервер работает как **Android Foreground Service**.

Используются:

* `Foreground Service`;
* `NotificationChannel`;
* `WifiLock`.

Это позволяет серверу продолжать работу даже при:

* 🔒 заблокированном экране;
* 🌙 переходе устройства в режим ожидания;
* 📶 попытках Android перевести Wi-Fi в спящий режим.

---

### ⚡ WebSocket-соединение

В основе сервера используется:

* **NanoHTTPD** — HTTP-сервер;
* **NanoWSD** — WebSocket-сервер.

WebSocket обеспечивает двустороннюю связь между сервером и клиентами с минимальными задержками.

```text
FM Server
    │
    ├── HTTP
    │
    └── WebSocket
          │
          ├── FM Client #1
          ├── FM Client #2
          └── FM Client #3
```

---

### 💓 Heartbeat

Сервер регулярно проверяет активность подключённых клиентов.

Каждые **10 секунд** выполняется проверка соединений через `Ping/Pong`.

Это позволяет автоматически обнаруживать:

* потерю Wi-Fi;
* отключение устройства;
* разрыв TCP-соединения;
* неактивные WebSocket-соединения.

---

### 💬 История сообщений

Сервер хранит в памяти последние **200 сообщений**.

При подключении нового клиента сервер автоматически отправляет ему сохранённую историю.

```text
Последние сообщения:
┌──────────────────────────────┐
│ 1. Привет!                   │
│ 2. Как дела?                 │
│ 3. Сервер уже работает       │
│ ...                          │
│ 200. Последнее сообщение     │
└──────────────────────────────┘
```

---

### 🌐 Встроенная веб-страница

При открытии IP-адреса сервера через обычный браузер отображается информационная страница.

Например:

```text
http://192.168.43.1:3550/
```

На странице можно увидеть:

* статус сервера;
* количество подключённых клиентов;
* информацию о FM Server.

Также доступны REST-эндпоинты:

| Endpoint   | Назначение                           |
| ---------- | ------------------------------------ |
| `/`        | Веб-интерфейс сервера                |
| `/status`  | Текущий статус сервера               |
| `/history` | История сообщений                    |
| WebSocket  | Обмен сообщениями в реальном времени |

# 📂 Структура проекта

```text
FMServer/
├── FMServer.java
├── ChatService.java
├── ClientManager.java
├── ChatWebSocket.java
├── Message.java
└── MainActivity.java
```

### `FMServer.java`

Основной HTTP/WebSocket-сервер на базе NanoHTTPD/NanoWSD.

Отвечает за:

* запуск HTTP-сервера;
* WebSocket Handshake;
* REST-эндпоинты;
* обработку HTTP-запросов.

---

### `ChatService.java`

Android `Foreground Service`, отвечающий за работу сервера в фоне.

Основные задачи:

* запуск FM Server;
* остановка FM Server;
* создание системного уведомления;
* удержание `WifiLock`;
* поддержание сервера при выключенном экране.

---

### `ClientManager.java`

Менеджер подключённых клиентов.

Отвечает за:

* регистрацию клиентов;
* удаление отключившихся клиентов;
* Broadcast сообщений;
* хранение истории;
* Heartbeat;
* Ping/Pong-проверки.

---

### `ChatWebSocket.java`

Обработчик WebSocket-соединений.

Работает с:

* подключением клиента;
* отключением клиента;
* текстовыми сообщениями;
* `join`;
* `typing`;
* входящими JSON-пакетами.

---

### `Message.java`

Модель сообщения.

Отвечает за:

* хранение данных сообщения;
* сериализацию в JSON;
* десериализацию JSON.

---

### `MainActivity.java`

Главный интерфейс приложения.

Позволяет:

* запускать сервер;
* останавливать сервер;
* отображать IP-адрес;
* отображать порт;
* показывать состояние сервера.

---

# 📦 Формат сообщений

Для обмена данными используется JSON.

Пример сообщения:

```json
{
  "type": "message",
  "sender": "Kirill",
  "text": "Привет!",
  "timestamp": 1750000000000
}
```

Пример события подключения:

```json
{
  "type": "join",
  "sender": "Kirill"
}
```

Пример события набора текста:

```json
{
  "type": "typing",
  "sender": "Kirill",
  "value": true
}
```

# 🔌 Подключение клиентов

Основным клиентом FM Server является **FM Client**.

Схема подключения:

```text
┌─────────────────┐
│   FM Server     │
│   Android      │
│                 │
│ 192.168.43.1    │
│     :3550       │
└────────┬────────┘
         │
      Wi-Fi
         │
    ┌────┴────┐
    │         │
    ▼         ▼
┌────────┐ ┌────────┐
│Client 1│ │Client 2│
└────────┘ └────────┘
```

Клиенту необходимо указать:

```text
Server IP: 192.168.43.1
Port:      3550
```

> ⚠️ IP-адрес зависит от конкретного Android-устройства и настроек Hotspot.

# 🏕 Использование в походе

FM Server рассчитан на работу в полностью автономной локальной сети.

### 1. Создайте Hotspot

На смартфоне, где установлен FM Server, включите **Wi-Fi точку доступа**.

Мобильный интернет включать **не нужно**.

```text
📱 FM Server
     │
     │ Wi-Fi Hotspot
     ▼
📱📱📱 Клиенты
```

### 2. Запустите FM Server

Откройте приложение и нажмите:

```text
[ ▶ Запустить сервер ]
```

После запуска приложение отобразит адрес сервера, например:

```text
Server: ONLINE

IP:   192.168.43.1
Port:  3550
```

### 3. Подключите участников

Другие устройства подключаются к Wi-Fi сети смартфона-сервера.

После подключения к сети запускается **FM Client**.

### 4. Укажите адрес сервера

```text
IP:   192.168.43.1
Port: 3550
```

После подключения клиент получает:

* историю сообщений;
* новые сообщения в реальном времени;
* статусы пользователей;
* события набора текста.

# 📡 Сетевая модель

FM Server создаёт локальную точку взаимодействия между устройствами.

```text
              ┌───────────────────┐
              │    FM Server      │
              │                   │
              │  HTTP : 3550      │
              │  WS   : 3550      │
              └─────────┬─────────┘
                        │
                 Local Wi-Fi
                        │
          ┌─────────────┼─────────────┐
          │             │             │
          ▼             ▼             ▼
     FM Client     FM Client     FM Client
```

Интернет для передачи сообщений **не используется**.

Все данные проходят непосредственно внутри локальной сети.

# 📦 Сборка и установка

## Требования

* Android Studio;
* Android SDK;
* JDK;
* Android-устройство с поддержкой Wi-Fi Hotspot.

## Сборка

Клонируйте репозиторий:

```bash
git clone <repository-url>
cd FMServer
```

Откройте проект в **Android Studio**.

Затем выполните:

```text
Build
  → Build Bundle(s) / APK(s)
  → Build APK(s)
```

После завершения сборки установите APK на Android-устройство.

# 🔐 Безопасность

FM Server предназначен для работы в **доверенной локальной сети**.

По умолчанию сервер не требует подключения к интернету и не использует внешний сервер для передачи сообщений.

> ⚠️ Если к вашей Wi-Fi сети имеют доступ посторонние устройства, они потенциально могут попытаться подключиться к FM Server.
